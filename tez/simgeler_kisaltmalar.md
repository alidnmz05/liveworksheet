# SİMGELER VE KISALTMALAR

## SİMGELER

| Simge | Açıklama |
| :--- | :--- |
| $\mathbf{A}, \mathbf{B}$ | Çok boyutlu uzayda cümleleri temsil eden yoğun vektörler (cümle gömmeleri) |
| $\theta$ | İki cümle vektörü arasındaki açı (Teta) |
| $\cos(\theta)$ | İki cümle vektörü arasındaki Kosinüs Benzerliği değeri |
| $\mathbf{A} \cdot \mathbf{B}$ | İki vektörün iç çarpımı (nokta çarpımı) |
| $\|\mathbf{A}\|$ | Vektörün $L_2$ normu (Öklid uzunluğu) |
| $\text{Sim}_{sem}$ | Sentence Transformers tarafından hesaplanan anlamsal benzerlik skoru |
| $\text{Ratio}_{fuzzy}$ | SequenceMatcher tarafından hesaplanan karakter düzeyinde bulanık eşleşme oranı |
| $\text{Skor}_{final}$ | Semantik skor ile bulanık eşleşme skorunun melezlenmesiyle elde edilen nihai AI skoru |
| $G$ | Branş bazlı tanımlanmış rakip kavram grubu kümesi (Theory Group Set) |
| $W_{ref}, W_{stu}$ | Referans doğru cevap ve öğrenci yanıtındaki benzersiz kelimeler kümesi |
| $T_{ref}, T_{stu}$ | Referans cevap ile öğrenci yanıtındaki ilgili kavram grubuna ait terim kümeleri |
| $T$ | Soru kelime uzunluğuna göre belirlenen dinamik değerlendirme eşik değeri (Threshold) |
